# Пиртобрутиниб — лендинг-концепт для специалистов

Концепт-макет страницы для специалистов здравоохранения: место пиртобрутиниба среди BTK-ингибиторов при ХЛЛ, данные РКИ BRUIN CLL-321 и CLL-314, профили пациентов, безопасность.

Учебный и демонстрационный материал, не является рекламой. Пиртобрутиниб в РФ не зарегистрирован.
Информация предназначена для медицинских и фармацевтических работников.
